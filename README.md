# NOOR2

Privacy-first, offline-first Quran companion for Android.

## Project Goal

NOOR2 aims to provide a reliable Quran experience that prioritizes:

- User privacy
- Offline functionality
- Accessibility
- Clear Arabic-first design
- Reliable Quranic content
- Maintainable Android architecture
