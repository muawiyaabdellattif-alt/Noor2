# Contributing to NOOR2

## Workflow

1. Read the project documentation.
2. Select or create an approved GitHub issue.
3. Create a dedicated branch.
4. Make one focused change.
5. Test the change.
6. Update relevant documentation.
7. Commit using a clear message.
8. Open a pull request.

## Commit Examples

- `docs: add project status`
- `feat: add Quran reader navigation`
- `fix: correct verse rendering`
- `test: add offline database tests`
- `chore: configure Android build`

## Rules

- Never commit secrets.
- Never modify Quranic content without verification.
- Keep changes focused.
- Document important decisions.
- Update project status after meaningful progress.
